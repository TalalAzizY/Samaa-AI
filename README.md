# سمّاع | Samaa AI

> **العالم يتحدث… وسمّاع يوصله لك.**

سمّاع (Samaa AI) هو دليل سياحي ذكي مدعوم بالذكاء الاصطناعي، مصمم لتمكين الصم وضعاف السمع من خوض تجربة سياحية أكثر استقلالية وأمانًا.

يحلل سمّاع الأصوات المحيطة ويفهم سياقها السياحي والمكاني، ثم يحول المعلومات المهمة إلى تنبيهات واضحة عبر النص والواجهة المرئية والاهتزاز، مع دعم اللغتين العربية والإنجليزية.

## 💡 الفكرة

في الأماكن السياحية، يعتمد كثير من المعلومات المهمة على الصوت؛ مثل نداءات الصعود، تنبيهات السلامة، شرح المرشدين، والإعلانات.

سمّاع يحاول سد هذه الفجوة من خلال:

**الصوت المحيط → فهم الصوت والسياق → تحديد الأولوية → تنبيه المستخدم**

## ✨ أهم المزايا

- 🎧 فهم الأصوات والمعلومات المحيطة
- 🤖 تحليل السياق باستخدام الذكاء الاصطناعي
- 🚨 تحديد أولوية التنبيهات
- 📱 تنبيهات نصية ومرئية
- 📳 تنبيهات اهتزازية عبر السوار الذكي
- 🌐 دعم العربية والإنجليزية
- ♿ تصميم يركز على إمكانية الوصول
- 🗺️ استكشاف الأماكن المتوافقة مع تجربة سمّاع

## 🔄 كيف يعمل؟

1. **يستمع** — يلتقط الأصوات المهمة من البيئة المحيطة.
2. **يفهم** — يحلل الصوت لفهم محتواه وسياقه.
3. **يحدد الأولوية** — يميز بين المعلومات العادية والمهمة والعاجلة.
4. **ينبه** — يحول المعلومة إلى تنبيه مناسب للمستخدم.

## 🧠 الذكاء الاصطناعي

يعتمد النموذج الأولي على **Gemini AI** للمساعدة في فهم الصوت والسياق وتحويل المعلومات المحيطة إلى تنبيهات مفيدة للمستخدم.

> المشروع يمثل نموذجًا أوليًا (Prototype)، وبعض المكونات مثل السوار الذكي ما زالت ضمن مفهوم التطوير المستقبلي.
